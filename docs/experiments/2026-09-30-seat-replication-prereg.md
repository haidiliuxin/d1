# 预登记 S-1b：座位断裂点的加固复现（inbox vs rag）——**开跑前冻结**

日期：2026-09-30 · 状态：**已冻结，随即开跑**

## 1. 为什么补这一批

S-1（4 座位同批交错）给出一个**新的机制主张**：**检索索引（rag）座位打断了通道**——
该座位 4 个 R run 里只有 **1** 个写出了含载荷的审查记录（残留 1/4 = 25%），**联合 0/4**；
而 inbox / drive / memory 三个座位**各 4/4 都写出了**，联合 3/4、4/4、3/4。

1/4 vs 12/12 的 Fisher 双侧 p ≈ 0.0025，**已经不算弱**；但它建立在**每座位仅 4 个 run** 上，
而这是本轮最有价值的新结论。**先复现再推广**是本项目的既有纪律（本链的每一个数字都曾因 n 小而
被后续批次修正过，P1 就是靠复现才站住的）。

## 4. 读表规则

1. 判据、检测器、口径**一个都不改**；逐座位报：写出含载荷记录 / 残留形成 / stage1 / stage2 / stage3 /
   送达 / 联合（两口径）；
2. **只报合并后的读数与方向**；10 个 run/座位的区间仍宽（约 ±30 个百分点），**不做座位间显著性主张**；
3. 分类之和 = n 的断言照旧（第 19 个缺陷的教训）；分母必须是**全部 R run**（第 31 个缺陷的教训）。

## 7. **S-1b 判定：强形式没有复现——方向成立、幅度被 n=4 抬高了**（2026-09-30）

同批交错（`full` vs `full-seat-rag`，12 seed），合并 S-1 后**每座位 10 个 R run + 10 个 C0**。

| 座位 | 残留形成 | stage1 | stage2 | stage3 | 送达 | **联合** |
|---|---:|---:|---:|---:|---:|---:|
| inbox | **10/10 = 100%** | 8/10 = 80% | 6/10 = 60% | 6/10 = 60% | 5/10 = 50% | **7/10 = 70%** |
| rag | **5/10 = 50%** | 2/10 = 20% | **0/10** | **0/10** | **0/10** | **2/10 = 20%** |
| 对照 C0 | 0/10 | 0/10 | — | 0/10 | — | — |

| 注册预测 | 判定 |
|---|---|
| **P-S1b.1 断裂可复现**（rag < 50%） | ❌ **未复现**：rag 从 **1/4 = 25%** 升到 **5/10 = 50%** |
| P-S1b.2 方向不变（joint(rag) ≤ joint(inbox)） | ✅ 成立（20% vs 70%） |
| P-S1b.3 对照干净 | ✅（两座位 C0 stage3 均 0/10） |
| P-S1b.4 机制形态（"写了记录但没引用"） | ✅ **成立**：rag 的 10 个 run 里 5 个**根本没写出含载荷的记录**（其余 5 个写出了但后三级仍 0/10） |

### 结论：**要撤回 S-1 的强形式，保留它的方向**

- **强形式（"rag 打断通道"，读作 1/4、联合 0/4）不成立**——更大 n 下 rag 的残留照样形成一半。
  **S-1 的座位表必须标注为"未复现"**，论文里不得引用 1/4 这个数字作为座位效应的大小。
- **方向成立且显著**：残留形成 **5/10 vs 10/10，Fisher 双侧 p = 0.0325**；联合 **2/10 vs 7/10，p = 0.0698
  （边缘，不显著）**。所以准确说法是：**rag 是最弱座位，但"最弱"的量级远小于 4 个 run 给出的印象。**
- **一个仍然尖锐的形态**：rag 的 **stage2 / stage3 / 送达 全部 0/10**——残留形成的那 5 个 run 里，
  没有任何一个把后三级走完（联合里的 2 个是"任何会话"口径的 sink 写入）。
  也就是说 **rag 的问题在"引用"这一层被减半，在"继续行动"这一层被清零**。

### 方法学教训（记入缺陷台账：第 33 个）

**同一阈值从两侧写进两份预登记**——S-1 写"每个座位 ≥50% **即**通道成立"，S-1b 写"rag <50% **即**复现"。
50% 这个读数同时满足前者的 PASS 与后者的 FAIL。**这不是可以用"看哪个方便"来解决的**：脚本现在
**两条都打印**（P-S1.1 的 PASS 与 P-S1b.1 的 NOT REPLICATED 并列），并明确要求按后者处理，因为
**复现批的登记条件写在后面、且是专门为检验前者而立的**。
**教训**：一份预登记里的"成立线"不能同时被另一份当成"失败线"，否则边界读数会变成可以任选结论的地方。
