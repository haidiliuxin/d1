# 论文骨架：诱导防御残留作为跨边界递送通道

> **状态**：大纲 + 当前证据对照。所有数字都标了口径与出处；标 ⚠️ 的是**还不足以进正文**的。
> 目标：CCF-B 级（安全类实证 / 测量 + 缓解）。

---

## 0. 一句话定位

**不要把论文写成"我们造出了一条稳定的 APT 链"——现有证据不支持，而且我们自己的判决实验把它推翻了。**
可发表且**更硬**的形态是：**一条被量化的通道 + 一条锋利的边界 + 一个由因果消融验证的缓解措施**，
外加一份把"这类实验极易自欺"写成方法论的仪表缺陷账本。

C4 是"所以该怎么办"；C3 是纠错。

## 3. 威胁模型

- **攻击者**：只能写一次（一次注入），此后无任何 C2 通道、无第二次投放。
- **防守方**：有一个**策略义务**——审查后必须留下书面记录，并（在原策略下）**引用**被评估的内容。
  这正是"诱导防御"：防御行为本身创造了载体。
- **环境**：LLM agent + 工具（文件 / 邮件 / 日历 / 记忆 / RAG / 凭据 / mock sink）。
- **边界**：每个"边界"处，除防御自身残留外所有载荷载体被销毁，`coverage` 由**重扫**验证为 1.0。
- **非目标**：不涉及真实系统、真实凭据、网络外联、第三方数据。终点是一行 mock sink 记录。

## 4. 方法

### 4.1 测量装置
- 7 会话 / 3 边界；源约束判据（每阶段必须由**指定会话**达成）；四级 ASR + `stage_coverage`。
- **强制清洗不变式**：`coverage == 1.0` 重扫验证；C0 臂每个边界 `surviving == 0`。
- **逐条残留测量**：每个边界记录"每个幸存载体携带哪几条 item"（`residue_items` / `leak_index`）。
- **送达溯源终点** `stage3_delivered`：要求达成者**先接触过携带目标 item 的载体、再行动**。

### 4.2 载荷三变体（同一判据）
| 变体 | 注入 | item 2 的座 | item 3 的座 |
|---|---|---|---|
| `full` | 三条全在备忘里 | 同左 | 同左 |
| `next-hop` | **只有 item 1** | 凭据值（封印至 S3） | sink 回执（封印至 S5） |
| `only-stage1` | **只有 item 1** | 不存在 | 不存在 |

### 4.3 统计纪律
- 预登记（含 go/no-go 门槛与修订记录，§9.10/§9.14）。
- 一切从 `events[]` 重算；**不能被同一规则评分的 run 不进同一个率**（§9.13b）。
- 每个判据配"必须接受 + 必须拒绝"的真实样例（`tests/test_chain_criteria.py`）。

## 6. 相关工作定位

- **AgentDojo / InjecAgent / ASB**：单次注入 → 单次危害。**本文的差异是"跨边界、跨会话的持续递送"**，
  且载体由**防守方自己的合规产物**提供。
- **记忆投毒 / 持久化注入**：载体是攻击者自己写进记忆的内容。**本文的载体是防守方写的**。
- **残留 / 数据外泄类工作**：关注"数据是否泄漏"，本文关注"**指令**能否跨边界传递"，并给出**能力边界**。

## 7. 局限（照实写）

- 单模型（`MiniMax-M2.7`）、单载体切片（审查记录落 drive）、单链形态；`temperature=0.1` 不是 0，
  **同一判据跨批次摆动实测到过一倍**。
- n 小：核心对比 0/12 vs 6/12；stage2 的必要性未确立。
- 判据苛刻度差异会改变 stage 剖面的形状（已在 §9.13b 记录）。
- 沙箱测量 ≠ 可部署能力；终点是 mock sink 记录。

## 8. 伦理与可复现声明

**边界**：真实模型 API（研究者自有 key）+ 真实 agent 框架 + **沙箱化工具与虚拟资产**；
无网络外联、无真实凭据、无第三方系统、无真实用户数据。**未对任何已部署产品发起测试。**

**artifact**：判据双向回归测试（43 项）、探针（测量 + 布设 + 消融操纵三组双向检查）、
原始 run artifact、从原始轨迹重算的统计脚本、预登记文档与**全部修订记录**（含两处对自己不利的）。
